## 1. 帳號：註冊、登入、忘記密碼

### 註冊

1. 進入「**建立帳號**」頁面，輸入 Email、密碼（至少 8 個字元）。
2. 閱讀「服務條款與醫療免責聲明」，勾選：
   - ☐ 我已閱讀並同意上方的服務條款與醫療免責聲明
   - ☐ 我已年滿 18 歲
3. 按下「**建立帳號**」。系統會顯示：「註冊完成！我們已寄出一封驗證信到您的信箱，請點開信中的連結完成驗證。現在也可以直接登入。」
4. 到信箱點開驗證信完成驗證。**Email 未驗證前無法上傳健檢報告、也無法使用健康問答**，畫面會提醒你完成驗證。

也可以用畫面上的「**使用 Google 登入**」按鈕，用 Google 帳號直接註冊／登入，不需另外設密碼。

### 登入

輸入 Email、密碼，按「**登入**」。登入成功後畫面顯示「前往我的健康專案」連結。

### 忘記密碼

1. 登入頁按「**忘記密碼？**」，進入「忘記密碼」頁面。
2. 輸入註冊時的 Email，按「**寄送重設信**」。
3. 系統一律顯示：「如果這個 Email 有註冊過，我們已寄出重設密碼的信。請在 **30 分鐘內**點開信中連結完成重設。」（不論這個 Email 是否真的存在，訊息都一樣，這是刻意的安全設計，避免被用來測試哪些 Email 有註冊過。）
4. 點開信中連結，進入「設定新密碼」頁面：
   - 若連結已過期或無效，會顯示：「這個重設連結已過期或無效。請回到「忘記密碼」重新申請一封信，並在 30 分鐘內點開信中連結。」——請重新申請一次。
   - 連結有效時輸入新密碼（至少 8 個字元），按「**設定新密碼**」。成功後顯示：「密碼已重設完成！請用新密碼重新登入。」

## 2. 健康專案管理

登入後的「**我的健康專案**」頁面，是所有專案的入口。

- **建立專案**：在「新增專案名稱」欄位輸入名稱（例如「媽媽」「我自己」），按「**建立專案**」。
- 每個專案卡片提供：**個人健康背景**、**健檢文件**、**趨勢分析** 連結，以及 **改名**、**封存／還原**、**刪除** 操作。
- **改名**：點「改名」後出現「專案名稱」輸入框，按「儲存」或「取消」。
- **封存**：點擊後會跳出確認：「確定要封存「{專案名稱}」嗎？封存後可隨時還原。」封存不會刪除資料，只是先收起來不顯示在列表，可隨時「還原」。
- **刪除**：點擊後跳出確認：「確定要刪除「{專案名稱}」嗎？刪除後將無法從列表中看到此專案。」

> 💡 每個帳號可以建立多個專案，建議一人一個專案（例如「我自己」「爸爸」「媽媽」分開建），資料才不會混在一起。目前每個專案只綁定建立它的那個帳號，暫不支援多人共用同一個專案。

## 3. 個人健康背景

專案內點「**個人健康背景**」，填寫過敏史、慢性病、目前用藥、運動相關資訊等等。這一頁**會自動儲存**（畫面顯示「儲存中…」→「✓ 已自動儲存」），填到一半離開也不會遺失。

這些內容目前不會被系統拿去做任何自動判讀，純粹是給你自己留存、之後跟醫師討論或回顧時參考用的背景資料。

## 4. 健檢文件：上傳、解析、確認

專案內點「**健檢文件**」。

1. 選擇 PDF 或照片檔（JPG／PNG，單檔上限 20MB），按「**開始上傳**」。系統會自動做安全掃描，可能需要數十秒。
2. 文件狀態依序為：**上傳中 → 解析中 → 待確認 → 已確認**（或失敗狀態：**上傳失敗**／**解析失敗**）。
3. 狀態變成「待確認」後，點「**查看解析結果**」，逐列檢查系統讀出的項目、數值、單位、參考區間：
   - 信心值偏低會標「待確認（0.xx）」，代表系統不太確定，需要你對照原始報告。
   - 每列可「**編輯**」修正、「**接受**」確認無誤、「**拒絕**」剔除誤判、或「**刪除**」整列移除。
   - 漏讀的項目可用「**手動新增一列**」自行補上。
4. 全部列都有明確結論後，按下「**確認**」。**任何沒有確認過的數據都不會進入正式紀錄**，這是系統刻意設計的安全機制，避免辨識錯誤的數字被誤用。

其他操作：「**預覽**」原始檔案、「**重新解析**」（僅解析失敗時可用）、「**刪除**」整份文件、「**編輯**」檢驗日期。

## 5. 健康戰情頁與趨勢分析

- **我的健康戰情**（專案首頁）：六個區塊，目前「目前健康狀態」與「早期變化」會顯示真實資料；其餘四個區塊（目前行動計畫、情境與應對、證據與不確定性、專業協助）尚在開發中，會誠實標示「尚未推出」。
- **趨勢分析**：每個檢驗項目各自一張折線圖＋資料表（日期、數值、參考區間、來源頁碼）。同一項目出現不同單位時，系統會拆成兩條線並提示「⚠ 偵測到同一項目出現不同單位，已拆開顯示避免錯誤連線」，避免誤導判讀。

兩頁都需要至少一份「已確認」的文件資料才會顯示內容，否則顯示「尚無已確認資料」。

## 6. 行動計畫（完整功能）

點戰情頁或趨勢分析頁尾的「**行動計畫**」連結，進入此頁。這是功能最完整的一個頁面，涵蓋「設定計畫 → 啟用前安全把關 → 執行追蹤 → 定期檢討 → 需要時轉介」整條流程。

### 6.1 建立一個新計畫

1. 按「**建立新計畫**」，填寫：
   - **標題**（必填，例如「三個月血壓控制計畫」）
   - **基準**：目前狀況的基準描述
   - **風險**：這個計畫可能有的風險
   - **停止條件**：什麼情況下應該停止這個計畫
   - **轉介條件**：什麼情況下應該轉介專業協助
   - **檢討日期**：預計何時回顧這個計畫
2. 按「**建立計畫**」。新計畫一開始是「**草稿**」狀態，還不會生效。

建立後，在計畫詳情裡繼續新增：

- **行動**區塊：輸入「行動描述」與「分類（可留空）」，按「**新增行動**」。
- **指標**區塊：輸入「指標名稱」，選擇分類（**領先指標**／**結果指標**／**安全指標**），按「**新增指標**」。

### 6.2 啟用計畫（安全把關機制）

準備齊全後按「**啟用**」。系統會檢查：**基準、風險、停止條件、轉介條件、檢討日期**都要填，而且**領先／結果／安全三種分類的指標都至少要有一筆**。

> 🔒 **這是刻意設計的安全機制**：計畫內容不完整就無法啟用，避免在缺乏基準與停止／轉介標準的情況下貿然開始執行。

如果資訊不齊全，會出現一段以「**尚未完成安全資訊，不能啟用計畫（缺漏：……）**」開頭的提示，括號裡列出的是系統內部欄位代號，不是中文欄位名稱，對照如下：

| 畫面顯示的代號 | 實際指的欄位 |
|---|---|
| `baseline` | 基準 |
| `riskNote` | 風險 |
| `stopCondition` | 停止條件 |
| `referralCondition` | 轉介條件 |
| `reviewDate` | 檢討日期 |
| `metric:leading` | 缺少「領先指標」分類的指標 |
| `metric:outcome` | 缺少「結果指標」分類的指標 |
| `metric:safety` | 缺少「安全指標」分類的指標 |

補齊缺漏的欄位或指標後再按一次「啟用」即可。

### 6.3 計畫狀態總覽

計畫卡片上的狀態徽章：

| 狀態 | 意思 |
|---|---|
| 草稿 | 剛建立，尚未啟用 |
| 資訊未齊全 | 曾嘗試啟用但資訊不足 |
| 安全審查中 | 系統正在檢查安全資訊 |
| 執行中 | 已啟用，正在追蹤 |
| 已暫停 | 手動暫停中，可恢復 |
| 已停止 | 已終止，**無法再恢復或編輯**（含因不良反應停止的計畫） |
| 待檢討 | 已到檢討日期 |
| 可能無效 | 定期檢討判斷可能無效 |
| 需要專業評估 | 定期檢討判斷需要專業評估 |
| 已封存 | 已封存收起 |

### 6.4 執行中：暫停、恢復、停止、調整

- **暫停**（僅執行中的計畫可按）／**恢復**（僅已暫停的計畫可按）：立即生效，不會跳出確認視窗。
- **停止**：終止計畫，同樣立即生效、無確認視窗，且**停止後無法恢復**。
- **調整（將建立新版本）**：對執行中／已暫停／可能無效／需要專業評估的計畫按下後，會開啟表單讓你修改基準、風險、停止／轉介條件、檢討日期，送出後系統會**建立一個新版本**（保留舊版本歷史），新版本會重新經過一次安全把關（6.2 的檢查機制）才能繼續執行。
- **刪除**：任何狀態的計畫都可以刪除。

> ⚠️ **重要**：系統**不會**因為計畫「可能無效」就自動幫你調整行動內容或加重強度——這是刻意的設計，任何調整都必須由你本人透過「調整」主動決定並送出新版本，避免系統自作主張改變你的健康計畫。

### 6.5 日常回報

執行中或已暫停的計畫，若已有指標，可在「**日常回報**」區塊記錄：

1. 選擇「**指標**」（下拉選單，預設「請選擇」）。
2. 填「**日期**」與「數值／狀況」，備註可留空。
3. 按「**新增回報**」。

回報可以「刪除」；若被系統標記已更正過，會顯示「（已更正）」。

### 6.6 症狀事件與不良反應標記

在「**症狀事件**」區塊記錄任何身體不適：

1. 填寫「描述你的症狀」與「發生時間」。
2. 如果這是**不良反應**，勾選「**這是不良反應，需要暫停計畫**」。
3. 按「**回報症狀**」。

已回報的症狀事件可標記狀態：「**標記觀察中**」「**標記已解決**」「**標記需要專業評估**」；如果一開始沒勾選不良反應，之後發現其實是不良反應，也可以用「**回溯標記為不良反應（將暫停計畫）**」（紅字顯示）補標記。

> 🔒 **不良反應標記是最高優先的安全機制**：只要症狀事件被標記為不良反應，**系統會立即停止相關計畫**，且比照 6.4「已停止」狀態，**沒有任何恢復路徑**——不能暫停、不能恢復、也不能調整，只能重新建立一個全新的計畫。這是刻意的設計：不良反應是需要人來判斷、不該由系統自動放行繼續執行的情況，寧可完全終止，也不留一條可能被誤用的「恢復」按鈕。

### 6.7 定期檢討（十分類）

到了檢討日期，計畫會顯示「**開始檢討**」按鈕（未到日期前顯示「尚未達檢討日期（日期）」）。按下後，從以下十個分類中選一個：

| 分類 |
|---|
| 有改善 |
| 部分改善 |
| 暫時穩定 |
| 尚未到檢討時間 |
| 執行資料不足 |
| 測量資料不可比較 |
| 計畫可能無效 |
| 計畫難以持續 |
| 出現不良反應 |
| 需要專業評估 |

可加註備註（可留空），按「**送出檢討**」完成。

- 選「**計畫可能無效**」→ 計畫狀態轉為「可能無效」。
- 選「**需要專業評估**」→ 計畫狀態轉為「需要專業評估」，同時解鎖下方「專業轉介摘要」功能。
- 選「**出現不良反應**」→ 比照 6.6，立即停止計畫。
- 其餘七類 → 計畫狀態不變，純粹留下紀錄。

> 已完成的檢討**無法修改或覆寫**，如需調整計畫方向，請用 6.4 的「調整」功能。

### 6.8 專業轉介摘要

只要有一筆檢討的分類是「**需要專業評估**」，就會解鎖「**產生轉介摘要**」按鈕。按下後系統會用結構化方式（非 AI 生成）整理出一份摘要，方便帶去看診。

摘要狀態：**草稿**（剛產生）→「標記已完成」→ **已完成** → 「標記已匯出」→ **已匯出**。摘要也可以隨時「刪除」。

## 7. 健康問答

點戰情頁尾的「**健康問答**」連結，進入問答頁。

1. 用上方「**對話：**」下拉選單切換既有對話，或按「**建立新對話**」開啟一個新的。
2. 在下方輸入框（提示文字：「輸入你想問的健康問題……」）打字，按「**送出**」。
3. 回答會即時逐字顯示，過程中送出按鈕會變成「**取消**」，可隨時中止。
4. 回答下方若有參考資料，會列出「**引用來源**」清單——這個系統的問答**只會引用你已確認的個人資料，或內建的衛教知識**，不會憑空編造內容。
5. 對任一則回答不滿意，可按「**重新產生**」再問一次。

**安全提示**：

- 如果你的專案還沒有足夠的已確認資料可以回答，會顯示：「目前的資料還不足以回答這個問題，建議補充更多健檢資料後再試。」
- 如果某則回答的用字偏向較強烈的醫療判斷語氣，會出現提醒：「這則回答可能包含較強烈的醫療判斷用語，請將其視為參考資訊，實際情況仍需諮詢專業醫師。」

**使用限制**：為避免濫用，每個帳號**每天有提問次數上限**（跨所有專案累計）。額度用完時會顯示：「今天已經問了不少問題了，明天再繼續聊聊吧！」隔天額度會重新計算。

## 8. 看診摘要與資料匯出

點戰情頁尾的「**看診摘要與資料匯出**」連結。

### 8.1 產生看診摘要

1. 勾選要包含的區塊（可複選）：
   - **背景（個人健康背景）**
   - **期間趨勢**（勾選後可指定起訖日期）
   - **執行中計畫**
   - **症狀事件**（勾選後可指定起訖日期）
   - **想問醫師的問題**（勾選後出現文字欄位，可先打好想問的問題）
2. 至少勾選一項，按「**產生看診摘要**」。
3. 產生後畫面顯示：「看診摘要已產生，可於下方預覽並列印／另存為 PDF。」下方會出現預覽內容，包含各區塊摘要（沒有內容的區塊顯示「無」）。
4. 按「**列印／另存為 PDF**」，會直接開啟瀏覽器的列印功能，你可以選擇印出來或存成 PDF 檔帶去看診。

> 💡 若某個執行中計畫最近的檢討結果是「需要專業評估」，摘要會特別用紅字標註提醒，方便就診時第一眼看到。

### 8.2 匯出資料

按「**匯出資料（ZIP）**」，會下載一個 ZIP 壓縮檔，內含這個專案的**結構化資料、趨勢資料（CSV）、以及所有你上傳過的原始檔案**，適合當作個人備份，或轉移到其他地方使用。

## 9. 帳號設定與刪除

點專案列表右上角「**帳號設定**」，可看到目前登入的 Email。

- **刪除帳號**：按下「**刪除帳號**」後跳出確認：「確定要刪除帳號嗎？您有 30 天的時間可以取消；30 天期滿後將永久刪除，無法復原。」
- 確認後進入「**帳號即將刪除**」狀態，畫面顯示確切的永久刪除日期，期間可隨時按「**取消刪除申請**」恢復正常使用。
- **30 天期滿後**，系統會永久刪除你所有的專案、文件與資料，**且無法復原**、也無法再用原本的帳密重新登入。

## 10. 附錄：常見錯誤訊息對照表

操作過程中若跳出以下文字，代表的意思：

| 你看到的訊息 | 代表的意思 |
|---|---|
| 尚未完成安全資訊，不能啟用計畫（缺漏：……） | 計畫某些必填欄位或指標分類還沒補齊，見 6.2 對照表 |
| 此計畫目前狀態無法啟用 | 計畫不是「草稿」或「資訊未齊全」狀態，通常代表已經啟用過了 |
| 只有啟用中的計畫可以暫停 ／ 只有暫停中的計畫可以恢復 | 按錯按鈕時機，計畫目前狀態跟操作對不上 |
| 已暫停相關行動，請先處理不舒服事件 | 這個計畫因不良反應已被停止，無法再暫停／恢復／編輯（見 6.6） |
| 此計畫已停止或已封存 | 計畫已經是終止狀態，無法再次停止 |
| 此計畫目前狀態無法編輯（已停止或已封存）。 | 已停止／已封存的計畫不能再調整內容 |
| 計畫尚未達檢討日，或已有進行中的檢討 | 還沒到檢討日期，或上一次檢討還沒送出完成 |
| 分類值不正確，或這筆檢討已完成 | 送出的檢討分類選項有誤，或這筆檢討已經處理過、不能再改 |
| 尚未有「需要專業評估」的檢討紀錄，無法產生轉介摘要 | 需要先完成一筆分類為「需要專業評估」的檢討，才能產生摘要 |
| 目前的資料還不足以回答這個問題 | 這個專案還沒有足夠的已確認健檢資料，健康問答無法回答 |
| 今天已經問了不少問題了，明天再繼續聊聊吧！ | 當日提問次數已達上限，隔天會重新計算 |
| 你沒有權限查看這個健康專案。 | 這個專案不屬於目前登入的帳號 |
| 連線發生問題，請確認網路後再試一次。 | 網路不穩定或暫時中斷，請檢查網路後重試 |
