# 健康管理網站規劃-規格整理 v 1.2.2

## 專案名稱

健康管理網站規劃

## 核心結論

這個產品不應被設計成「AI 直接給處方」，而應是： **把多年健檢資料整理成一個可追蹤、可驗證、可升級真人判讀的健康管理戰情表。**

AI 建議不是保證結果，而是**可追蹤的假設**。

## 產品定位

- 第一階段：健康管理與風險提醒工具  
- 非定位：醫療診斷、治療保證、線上處方  
- 路線：單一 HTML Demo → React 前端專案 → 串接 LLM / 檔案分析

## 目標客群

- 核心客群：50–65 歲  
- 高齡客群：65 歲以上  
- 青壯年客群：35–50 歲

## 產品目標

- 將多期健檢 PDF 轉成可比較的時間序列資料  
- 產生健康 Dashboard 與 AI 分析報告  
- 提供最佳 / 一般 / 最差三情境預估  
- 當 AI 建議風險高或衝突高時，引導真人介入

## 第一層 Dashboard 要解的 5 件事

1. 把建議變成可驗證假設  
2. 把衝突資訊顯示出來  
3. 把風險升級條件定義清楚  
4. 把運動傷害與錯誤執行納入模型  
5. 把「沒改善」變成正常分支，而不是系統失敗

## In Scope

- 註冊 / 登入 / Google 第三方登入  
- 個人資料編輯  
- Hero Page  
- 健檢 PDF 上傳、預覽、解析、存檔  
- 專案制健康資料管理  
- AI 摘要與趨勢分析  
- 三情境預估  
- 行動建議  
- 真人諮詢升級入口  
- 中醫 / 命理輔助觀點區塊  
- Streaming 報告輸出  
- Dashboard 視覺化

## Out of Scope（第一版不做）

- 線上處方與診斷  
- 直接串接醫院系統  
- 保險理賠整合  
- 視訊看診  
- 多角色醫療後台

## 系統核心原則

- 所有功能都必須考慮 state 與持久化  
- 所有新增資料皆需有 Create / Update / Delete  
- 所有上傳需有預覽  
- 所有縮放維持原始寬高比  
- 所有 LLM 輸出必須 Streaming  
- 支援開啟既有專案並繼續編輯

## 核心模組

- Auth Module  
- User Profile Module  
- Project Module  
- File Upload & Preview Module  
- Report Parsing Module  
- Normalization Module  
- Health Timeline Module  
- AI Analysis Module  
- Scenario Engine Module  
- Recommendation Module  
- Expert Escalation Module  
- TCM / Metaphysics Insight Module  
- Notification Module  
- Audit & Versioning Module

## 主要流程

1. 進入 Hero Page  
2. 註冊 / 登入  
3. 建立健康專案  
4. 填寫基本資料  
5. 上傳健檢 PDF  
6. 預覽 PDF  
7. 解析報告  
8. 人工校正欄位  
9. 產生 Dashboard 與三情境報告  
10. 需要時升級真人諮詢

## 核心資料物件

### User

- Create / Read / Update / Delete  
- State：active / suspended / deleted

### Project

- Create / Read / Update / Delete  
- State：draft / active / archived / deleted

### HealthReport

- Create / Read / Update / Delete  
- State：uploaded / parsing / parsed / needs_review / approved / deleted / parse_failed

### MetricSnapshot

- Create / Read / Update / Delete  
- State：raw / normalized / verified / deprecated

### RecommendationPlan

- Create / Read / Update / Delete  
- State：draft / streaming / published / superseded / withdrawn

### ExpertRequest

- Create / Read / Update / Delete  
- State：requested / assigned / scheduled / completed / cancelled

## Dashboard 主要區塊

- 健康總覽橫幅  
- 三情境預估卡  
- 衝突與提醒卡  
- 指標趨勢圖  
- AI 串流分析區  
- 升級真人介入區

## 驗收條件

1. 使用者可建立帳號並登入  
2. 支援 Google 第三方登入  
3. 可建立至少一個健康專案  
4. 可上傳 PDF，且上傳後可預覽  
5. 可從同一專案追加多期報告  
6. 可解析出至少一組可視化時間序列指標  
7. AI 報告以 Streaming 顯示  
8. 可生成最佳 / 一般 / 最差三情境  
9. 可顯示衝突建議與升級真人按鈕  
10. 關閉後再次開啟仍可續編同一專案

## 邊界與風險

- 健檢 PDF 格式不一致  
- 指標名稱與單位需標準化  
- 資料不足時不應給強結論  
- 中醫 / 命理內容不得與主要醫療建議混寫  
- 連續未改善時，應升級真人介入而不是繼續硬給 AI 建議

## 非技術白話版結論

這是一個幫你整理多年健檢資料的健康管理網站。 你可以把每年的健檢報告、每三個月的抽血與驗尿報告放進來，系統會幫你整理成直觀的健康戰情表，讓你知道：

- 哪些地方正在變好  
- 哪些地方需要注意  
- 接下來三個月大概會往哪個方向走  
- 你現在最值得優先處理的是什麼  
- 什麼時候應該找真人專家幫忙

## 分階段開發計畫

- Stage 1：做出 Hero Page 與單頁導覽 Demo

- Stage 8：補齊整合測試、回歸測試、邊界測試  
- Stage 9：文件化與交付
